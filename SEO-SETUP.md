# Search setup

1. Publish the files on GitHub Pages.
2. Rename `sitemap-template.xml` to `sitemap.xml` and replace both placeholders with your actual GitHub Pages address.
3. Add this line to `robots.txt` after replacing the address:

   `Sitemap: https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/sitemap.xml`

4. Add the site to Google Search Console, verify ownership, and request indexing for the homepage.
5. Do not expect instant traffic. Add genuinely helpful role-specific pages over time, based on questions job seekers actually ask.

## Optional analytics

Create an analytics property with the provider you choose, then put its measurement ID in `config.js`. Add that provider's approved script only after you have the correct ID and understand its privacy requirements.
